Deployment & Testing Options

Choose how you want to use or preview the chatbot widget on your website.

Option 1: HTML Script Tag (For Production)

Paste this script tag into the <head> or <body> of your website HTML files. 

<script src="http://localhost:8000/widget.js" data-api-url="http://localhost:8000" data-chatbot-id="cb_30abc2477366" data-bot-name="DocAgent AI" data-color="#8B5CF6" data-greeting="Hello!" defer></script>
Option 2: Browser Console Code (For Instant Testing)

Open your target website, press F12 (or right-click → Inspect) to open Developer Tools, go to the Console tab, paste the code below, and press Enter to instantly preview the chatbot. 

const script = document.createElement('script');
script.src = "http://localhost:8000/widget.js";
script.setAttribute('data-api-url', "http://localhost:8000");
script.setAttribute('data-chatbot-id', "cb_30abc2477366");
script.setAttribute('data-bot-name', "DocAgent AI");
script.setAttribute('data-color', "#8B5CF6");
script.setAttribute('data-greeting', "Hello!");
script.defer = true;
document.body.appendChild(script);
